# Frontend — Next.js + Tailwind (Orb Chase)

A minimalist three-page game built with Next.js (App Router) and Tailwind CSS.

- Pages: `/` (Landing), `/game`, `/game-over?score=`, `/leaderboard`
- State: Zustand
- Motion: Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Build:
```bash
npm run build
npm start
```

## Notes
- Uses a purple → sky gradient accent to match the Design System
- Fully responsive, clean, and accessible by default
